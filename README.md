# Online Store - Vibe Corner

Учебный проект интернет-магазина на чистом JavaScript без использования фреймворков.
Реализован каталог товаров с сезонной фильтрацией, корзина с сохранением в localStorage,
форма оформления заказа, приветственное модальное окно и учебная админ-панель для просмотра заказов.

## Demo

## Стек

- HTML5 (semantic markup)
- CSS3 (Flexbox, Grid, media queries, CSS-переменные)
- JavaScript (ES6+, DOM API, localStorage)

Без фреймворков и библиотек. Единственное внешнее подключение - Google Fonts.

## Функциональность

### Каталог
- Сетка товаров с карточками: изображение, название, цена, кнопка «Добавить в корзину»
- Фильтр по сезонам: Весна, Лето, Осень, Зима
- Режим «Все товары» показывает полный каталог без привязки к сезону
- 24 товара, разбитых по четырём сезонным коллекциям

### Корзина
- Добавление товара по клику на кнопку
- Изменение количества кнопками «+» и «−»
- Удаление товара
- Автоматический пересчёт итоговой суммы
- Счётчик товаров в шапке сайта
- Сохранение корзины в localStorage между сессиями

### Оформление заказа
- Модальное окно с полями: имя, фамилия, адрес доставки, контактный телефон
- Валидация всех полей перед отправкой
- Сообщение «Заказ создан!» после успешной отправки
- Сохранение каждого заказа в localStorage

### Админ-панель (учебная)
- Открывается по адресу `?admin=1` в URL
- Показывает список оформленных заказов: клиент, контакты, состав заказа, сумма
- Работает на localStorage браузера - данные видны только на том устройстве, где заказы были оформлены

### Оформление и адаптив
- Четыре сезонные цветовые темы: весна, лето, осень, зима
- Переключение темы меняет палитру, баннер, карусель и вид частиц
- Летающие частицы: лепестки, зелёные капли, осенние листья, снежинки
- В режиме «Все товары» - смешанные частицы и нейтральная лавандовая палитра
- Приветственное модальное окно с шестью товарами (показывается один раз)
- Адаптивная вёрстка: 3 колонки на ноутбуке, 2 на планшете, 1 на телефоне

## Локальный запуск

Клонировать репозиторий:

```
git clone https://github.com/emopudge/online-shop-vanilla-js.git
cd online-shop-vanilla-js
```


Открыть `index.html` в браузере или запустить через расширение Live Server в VS Code.

## Хранение данных

Проект работает без серверной части, поэтому все данные хранятся в localStorage браузера:

| Ключ | Что хранит |
|---|------|
| `store-cart` | Содержимое корзины: id товаров и их количество |
| `store-season` | Последний выбранный сезон |
| `store-welcome-shown` | Флаг, что приветственное окно уже было показано |
| `store-orders` | Список оформленных заказов для админ-панели |

## Проверка функциональности

### Корзина
1. Кликнуть «Добавить в корзину» на нескольких товарах
2. Открыть корзину кнопкой в шапке - товары и сумма на месте
3. Изменить количество, удалить товар - сумма пересчитывается
4. Обновить страницу - корзина сохранилась

### Оформление заказа
1. Открыть корзину, нажать «Оформить заказ»
2. Попробовать отправить пустую форму - появятся подсказки об ошибках
3. Заполнить все поля корректно, нажать «Создать заказ»
4. Появится сообщение «Заказ создан!», корзина очистится

### Админ-панель
1. Оформить один или несколько заказов
2. Открыть адрес `?admin=1` в URL - например, `https://emopudge.github.io/online-shop-vanilla-js/?admin=1`
3. Просмотреть список заказов
