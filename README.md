# Online Store


Учебный проект интернет-магазина на чистом JavaScript без использования фреймворков.
Реализован каталог товаров, корзина с сохранением в localStorage, форма оформления заказа
и адаптивная вёрстка для ноутбуков, планшетов и смартфонов.


## Стек


- HTML5 (semantic markup)
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (ES6+, DOM API, localStorage)


## Функциональность


- Каталог товаров с карточками (название, цена, кнопка «Добавить в корзину»)
- Корзина: добавление, удаление, изменение количества
- Автоматический пересчёт итоговой суммы
- Сохранение корзины в localStorage между сессиями
- Модальное окно оформления заказа с валидацией полей
- Сообщение «Заказ создан!» после отправки формы
- Адаптивная вёрстка: 3 колонки на ноутбуке, 2 на планшете, 1 на телефоне
